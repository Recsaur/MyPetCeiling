<h1>===INTRODUCING THE CEILING DESKTOP PET!!!===</h1>
<p>Ceiling is a desktop pet which you can run on your desktop. It moves around with a silly animation, it'll make a squeak sound when you click on it and you can drop it around
your screen. You can also use built in tools that it has like making notes with its' notepad (that's currently the only tool, but more will hopefully be added).</p>

<h2>===How to Install===</h2>
<p>You can install it <a href="https://recsaur.itch.io/ceiling-desktop-pet">here</a> on my itch io page. When you
click download, a .exe file will download and you need to just run it for Ceiling to appear</p>

<h2>===Inspiration===</h2>
<p>Ceiling was made as I said because of the Hackclub event Ceiling, where you code something for some hours and
they ship you a seal plush (Ceiling). The desktop pet idea was originally a project that I had in mind
where I made BMO from Adventure Time as a desktop pet, but I repurposed it to Ceiling (I might continue with the
BMO pet idea where you can play simple games using him).</p>
